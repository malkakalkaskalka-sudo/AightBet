Clear Your Cache

If the site looks outdated or a feature isn't working, clearing your cache usually fixes it.

🤖
Android — Chrome
Most common on Android
  1. Tap the three dots (⋮) in the top-right corner
  2. Go to Settings → Privacy and security
  3. Tap Clear browsing data
  4. Check Cached images and files (uncheck others if you want)
  5. Tap Clear data — done ✓
🍎
iPhone — Safari
Default iPhone browser
  1. Open the Settings app (not Safari itself)
  2. Scroll down and tap Safari
  3. Tap Clear History and Website Data
  4. Confirm — done ✓
🌐
iPhone — Chrome
If you use Chrome on iOS
  1. Tap the three dots (⋯) at the bottom
  2. Go to Settings → Privacy
  3. Tap Clear Browsing Data
  4. Check Cached Images and Files
  5. Tap Clear Browsing Data — done ✓
🖥️
Desktop — Chrome / Edge
Windows or Mac
  1. Press Ctrl + Shift + R for a quick hard reload (easiest)
  2. Or open DevTools with F12, then right-click the reload button 🔄 and pick "Empty Cache and Hard Reload"
  3. Or press Ctrl + Shift + Del, check Cached images and files, click Clear data
On Mac use Cmd instead of Ctrl
After clearing cache, reload the page and the site should be fully up to date. If you still see issues, try logging out and back in.
